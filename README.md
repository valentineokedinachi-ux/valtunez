# VALTUNEZ v3 — by Okedinachi Valentine

Open with VS Code **Live Server** (right-click index.html → Open with Live Server).

- Your photo: save it as `assets/okedinachi.jpg`
- Artists: edit the `ARTISTS` list in `config.js` (photos load automatically)
- More full songs: add a free Jamendo key in `config.js`
- Offline: tap ↓ on a song marked FULL. Audio and lyrics are saved on the device.

Folder: `index.html` · `style.css` · `config.js` · `js/` (utils, sources, lyrics, offline, player, ui, app) · `sw.js` · `manifest.webmanifest`

## Deploy (free) so it installs like an app
Needs HTTPS. Easiest: drag the whole `valtunez-v3` folder onto https://app.netlify.com/drop (or use Cloudflare Pages / Vercel / GitHub Pages).
Open the link on your phone: Android Chrome → "Install app"; iPhone Safari → Share → "Add to Home Screen".
